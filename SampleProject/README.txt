SampleProject für RPG Maker 3D Engine

Dieses Projekt ist ein Beispiel für die Struktur eines RPG Maker 3D Spiels.

Ordner:
- assets/textures: PNG Tilesets
- assets/models: OBJ Modelle
- assets/audio: OGG/MP3/WAV Sounds
- maps: Binäre Map Dateien (.map)
- scripts: Ruby Scripts (.rb)
- prefabs: Prefab Dateien (.prefab)
- database: JSON Datenbank (Actors, Items, etc)
- saves: Spielstände

Starte die Engine mit:
RPGMaker3D.exe --project ./SampleProject --editor

Oder direkt testen:
RPGMaker3D.exe --project ./SampleProject --play
